
# 🚀 Full Admin CMS + UI Upgrade Plan for Voquarn Code

## Overview
Add a complete admin dashboard with authentication (NextAuth.js), full CMS capability (blog, services, portfolio, team, testimonials, FAQ, pricing), shadcn/ui components, TipTap rich text editor, and improved blog card designs — all integrated with your existing Neon PostgreSQL database.

---

## Phase 1: Setup & Dependencies

### 1.1 Install new packages
```bash
npm install next-auth@beta @auth/drizzle-adapter bcryptjs ts-md5
npm install class-variance-authority clsx tailwind-merge tailwindcss-animate
npm install @tiptap/react @tiptap/starter-kit @tiptap/extension-image @tiptap/extension-link @tiptap/extension-placeholder
npm install sonner
npm install lucide-react  # already installed
npm install -D @types/bcryptjs
```

### 1.2 Initialize shadcn/ui
Run `npx shadcn@latest init` to set up:
- `src/lib/utils.ts` (cn helper)
- `src/components/ui/` directory (shadcn components)
- CSS variables for shadcn theming

### 1.3 Install shadcn/ui components
```
npx shadcn@latest add button card input label textarea select dialog table badge toast dropdown-menu separator sheet sidebar avatar tabs switch
```

## Phase 2: Database Schema (Drizzle ORM)

### 2.1 Extend `src/db/schema.ts` — Add tables:

**Users & Auth:**
- `users` — id, name, email, emailVerified, image, role (admin/member), createdAt
- `accounts` — id, userId, type, provider, providerAccountId, ...
- `sessions` — id, userId, token, expires
- `verificationTokens` — id, identifier, token, expires

**CMS Content:**
- `blog_posts` — id, slug, title, excerpt, content (rich text JSON), coverImage, category, published, publishedAt, readTime, createdAt, updatedAt
- `blog_images` — id, blogPostId, url, altText (for image upload)
- `services` — id, title, description, deliverables (JSON), slug, icon, createdAt, updatedAt
- `sub_services` — id, serviceId, name, description, pricePkr, priceUsd, features (JSON), slug
- `portfolio_items` — id, slug, title, category, summary, outcome, stack (JSON), liveUrl, imageUrl, createdAt
- `team_members` — id, name, role, bio, imageUrl, order, createdAt
- `testimonials` — id, name, company, review, stars, order, createdAt
- `faq_items` — id, question, answer, order, createdAt
- `pricing_plans` — id, name, description, pricePkr, priceUsd, featured, features (JSON), order, createdAt
- `site_settings` — id, key, value (for editable site-wide settings)

### 2.2 Run `npx drizzle-kit push` to sync schema

## Phase 3: Authentication (NextAuth.js v5)

### 3.1 Auth configuration
- Create `src/lib/auth.ts` — NextAuth config with:
  - Credentials provider (email/password login)
  - Drizzle adapter for database sessions
  - bcryptjs for password hashing
  - JWT session strategy

### 3.2 Auth route handler
- Create `src/app/api/auth/[...nextauth]/route.ts`

### 3.3 Auth middleware
- Create `src/middleware.ts` — Protect `/admin/*` routes
  - Redirect to `/admin/login` if not authenticated
  - Allow public pages through

### 3.4 Admin login page
- Create `src/app/admin/login/page.tsx` — Clean login form with email/password
  - Custom styled to match brand (#ff5400 accent)
  - Error/success toast notifications

### 3.5 Seed first admin user
- Create `scripts/seed-admin.ts` — CLI script to create first admin user
- Or a simple API route `POST /api/auth/seed` (protected, runs once)

## Phase 6: API Routes (Admin CRUD)

### 6.1 Blog API
- `GET /api/admin/blog` — List all blog posts
- `POST /api/admin/blog` — Create blog post
- `GET /api/admin/blog/[id]` — Get single post
- `PUT /api/admin/blog/[id]` — Update blog post
- `DELETE /api/admin/blog/[id]` — Delete blog post

### 6.2 Services API
- `GET/POST /api/admin/services`
- `GET/PUT/DELETE /api/admin/services/[id]`
- `POST/PUT/DELETE /api/admin/services/[id]/sub-services/[subId]`

### 6.3 Portfolio API
- Full CRUD at `/api/admin/portfolio`

### 6.4 Team API
- Full CRUD at `/api/admin/team`

### 6.5 Testimonials API
- Full CRUD at `/api/admin/testimonials`

### 6.6 FAQ API
- Full CRUD at `/api/admin/faq`

### 6.7 Pricing API
- Full CRUD at `/api/admin/pricing`

### 6.8 Upload API
- `POST /api/admin/upload` — Image/file upload to `public/uploads/`

### 6.9 Settings API
- `GET/PUT /api/admin/settings`

All admin API routes will be protected — check authentication server-side.
